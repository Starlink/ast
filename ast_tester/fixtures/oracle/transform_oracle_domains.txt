# Sampling domains for simplify fixtures, read by gen_transform_oracle.
#
# A native dump carries no domain of its own, so by default each input of a
# simplify fixture takes either sign with a magnitude spread logarithmically from
# 1e-3 to 1e3.  A fixture that is defined, or is the identity, only over some
# other range is given that range here, keyed on its .map relpath:
#
#   <relpath> <range>                         the same range on every input axis
#   <relpath> <range1> ... <rangeN>           one range per input axis
#
# where each <range> is two numbers, <lo> <hi>, or one of these names:
#
#   lon    a longitude, -pi to +pi
#   lat    a latitude, -1.5 to +1.5, short of the poles, where longitude is
#          undefined and close to which it is ill-conditioned
#
# The fixture's inputs are then sampled uniformly over the range, and an axis
# whose <lo> equals its <hi> is held at that value.  Its .simp
# partner is sampled at the same points, since check_transform_oracle compares
# the two row by row.  Only the forward inputs are declared: the inverse section
# is sampled at the forward outputs.
#
# The generator fails on an entry that names no fixture, or whose number of
# ranges is neither one nor the fixture's Nin.  Every entry needs a comment
# saying what the range is and why the default misses it.
#
# Blank lines and lines starting with '#' are ignored.

# A 2-D Box seen in a 3-D Frame through a PermMap that sets axis 3 to 5, so the
# Region is the slice z = 5 of the Box, and its simplification is a 3-D Box
# with no extent on axis 3.  The slice is sampled, since uniform sampling across
# it would land on it only once.  Off the slice the two forms differ, because the
# unsimplified Region tests a point by mapping it back to its 2-D base Frame,
# which discards axis 3; that is a Region defect to be fixed separately, with
# its own test.
